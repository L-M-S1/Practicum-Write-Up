When I was preparing for the AWS CP certification exam I naively believed I was ready to sit for it after only using one method of study. I took, repeatedly, the AWS  provided practice exam and while I did great on it, often scoring above passing by a significant margin, I did not include any other exams with rotating questions. After a point the practice exam became more about muscle memory than memory recall.

Upon taking the true exam, I quickly realized that I had made a mistake, but I muscled through the questions and managed to fail by only ~30 points. Not bad for being extremely underprepared.

If I could go back and redo the exam, truthfully I am unsure if I would change anything as I began watching the videos for the AWS Associate Developer exam and quickly realized I did not want to do this for the rest of my life.
